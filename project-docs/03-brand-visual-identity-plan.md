## 三、配色体系

### 3.1 主色板

| 色名       | 色值      | Pantone       | 使用场景                   |
| ---------- | --------- | ------------- | -------------------------- |
| **宁静蓝** | `#4A90D9` | PANTONE 279 C | 主Logo色、主按钮、标题强调 |
| **深蓝**   | `#2C5F8A` | PANTONE 294 C | 深色背景、导航栏           |
| **治愈绿** | `#7BC8A4` | PANTONE 345 C | 疗愈相关元素、正向指标     |
| **温暖橙** | `#F5A623` | PANTONE 143 C | 警示/提醒、CTA按钮         |
| **柔和白** | `#FAFAFA` | —             | 页面底色                   |
| **深灰**   | `#333333` | —             | 正文文字                   |
| **中灰**   | `#999999` | —             | 辅助文字                   |

### 3.2 渐变色

```
治愈蓝绿渐变：
  linear-gradient(135deg, #4A90D9 → #7BC8A4)
  用于：Logo高光、按钮、卡片背景

温暖日落渐变：
  linear-gradient(135deg, #F5A623 → #E8734A)
  用于：CTA按钮、重要提醒

深空渐变：
  linear-gradient(180deg, #1B2A4A → #2C5F8A)
  用于：深色背景页、PPT封面
```

## 五、Logo应用规范

### 5.1 最小安全空间

```
        ┌─────────────────────┐
        │    ←── 2x ──→       │
        │  ┌─────────────┐    │
        │  │             │    │
     ↑  │  │   [Logo]    │    │  ↑
     2x │  │             │    │  2x
     ↓  │  └─────────────┘    │
        │                     │
        │  ← 心安动识 →       │
        │                     │
        └─────────────────────┘
        ←──────── 4x ─────────→

规则：Logo周围保留至少2倍于Logo高度的空白区域
```

### 5.2 最小尺寸

- 印刷品：Logo高度不小于 **15mm**
- 数字屏幕：Logo高度不小于 **48px**
- 图标/Favicon：单独使用图形符号，不小于 **16×16px**

### 5.3 使用禁忌

| ❌ 禁止        | 说明                     |
| -------------- | ------------------------ |
| 拉伸变形       | 不可改变Logo宽高比       |
| 改变颜色       | 不可使用非品牌色系       |
| 添加阴影/描边  | 不可添加额外效果         |
| 旋转/镜像      | 不可旋转或翻转           |
| 低对比度背景   | 确保Logo与背景有足够对比 |
| 与其他元素拥挤 | 保持安全空间             |

## 六、品牌图案与辅助图形

### 6.1 辅助图形提取

从Logo中提取以下元素作为品牌辅助图形：

**圆环元素**：

- 用于：卡片边框、进度环、图标底
- 可缩放、可半透明、可渐变

**心形元素**：

- 用于：点赞/收藏图标、情感标识
- 小型装饰、水印

**眼睛/视线元素**：

- 用于：AI/检测相关模块标识
- 数据可视化中的"洞察"图标

### 6.2 底纹与纹理

- **渐变波纹**：宁静蓝到治愈绿的柔和渐变波纹，用于PPT背景、官网Hero区域
- **点阵网格**：品牌蓝灰色小点阵，用于数据可视化背景、技术页面
- **植物剪影**：柔和的叶片/花瓣剪影，用于疗愈内容页面

## 八、品牌声音与文案风格

### 8.1 文案语调

| 场景      | 语调          | 示例                                   |
| --------- | ------------- | -------------------------------------- |
| 品牌介绍  | 温暖+专业     | "用科技看见焦虑，以爱心守护心灵"       |
| 产品功能  | 清晰+鼓励     | "检测到咬指甲行为，试试这个替代动作吧" |
| 提醒通知  | 温柔+不评判   | "没关系，我们一起慢慢来"               |
| 数据报告  | 客观+正向     | "本周焦虑行为减少23%，你做得很好"      |
| 错误/异常 | 安抚+行动导向 | "出了点小问题，我们正在修复中"         |

### 8.2 禁用词与敏感词

| ❌ 避免使用 | ✅ 替代表述        |
| ----------- | ------------------ |
| "坏习惯"    | "无意识的焦虑行为" |
| "病人/患者" | "用户/来访者"      |
| "治疗"      | "干预/改善/疗愈"   |
| "不正常"    | "值得关注的信号"   |
| "监控/监视" | "陪伴/守护/关注"   |

### 8.3 品牌声音关键词

> 陪伴而非监控 · 理解而非评判 · 引导而非说教 · 温暖而非冰冷

## 九、Logo设计交付建议

### 推荐设计工具

- **Figma**（免费，协作方便）：适合初步草稿和团队协作
- **Adobe Illustrator**（专业）：适合最终矢量稿
- **Canva**（快速）：适合非设计师快速出图

### 推荐设计平台

- **猪八戒网/一品威客**：预算 ¥500-¥2000，获取专业设计师方案
- **99designs**：国际设计竞赛平台，适合获取多样化方案
- **AI生成工具**：Midjourney/DALL·E生成灵感草图 → 人工精细调整
