## 1. 项目概述

### 1.1 项目背景

在快节奏的现代社会，焦虑已成为影响全民心理健康的核心问题之一。《中国国民心理健康发展报告（2023-2024）》显示，我国成年人焦虑障碍的终生患病率约为7.6%，青少年群体中焦虑情绪检出率高达24.6%。焦虑情绪往往不以言语表达，而是通过躯体化动作无意识地呈现——咬指甲、拔头发、抓挠皮肤、抖腿、反复搓手、抠手指等身体聚焦重复行为（Body-Focused Repetitive Behaviors, BFRBs），这些行为既是焦虑的外在表征，又会反向加重患者的心理负担，形成恶性循环。

当前，针对此类行为的检测手段严重滞后：临床依赖人工观察与患者自我报告，主观性强、无法实现全天候监测；现有智能穿戴方案存在传感器维度单一、识别精度不足、功耗过高、难以落地等痛点。**市场上尚无一套集"精准识别—智能分析—心理干预—持续疗愈"于一体的全流程解决方案。**

### 1.2 项目定位

**「心安动识」** 是一套面向不同群体（儿童青少年、职场人群、老年群体）的情绪焦虑躯体化动作识别与心理疗愈平台。项目以**多传感器融合感知 + 计算机视觉（YOLO）+ 深度学习异常检测**为技术底座，以**数字化心理干预（CBT、正念、生物反馈）**为疗愈引擎，打造"**检测-分析-干预-康复**"四位一体的闭环服务体系。

### 1.3 项目愿景

> **让每一份无声的焦虑，都能被看见、被理解、被疗愈。**

我们致力于成为中国领先的**情绪躯体化行为智能识别与数字心理健康**解决方案提供商，以科技之力守护全民心理健康，助力"健康中国2030"战略落地。

### 1.4 核心差异化优势

| 维度     | 传统方案            | 心安动识                                     |
| -------- | ------------------- | -------------------------------------------- |
| 检测方式 | 人工观察/单一传感器 | **多传感器融合 + YOLO视觉 + 深度学习**       |
| 识别精度 | 主观性强，漏检率高  | **≥90% 精准识别 8+ 类 BFRBs**                |
| 覆盖场景 | 临床单点            | **临床+居家+办公+学校 全场景**               |
| 疗愈能力 | 无                  | **CBT数字疗法 + 正念引导 + 生物反馈**        |
| 商业模式 | 单一硬件销售        | **硬件+软件SaaS+周边+数据服务 多元盈利**     |
| 学术背书 | 无                  | **教授团队 + 软著 + 专利 + 论文 全链条支撑** |

### 5.2 核心技术详解

#### 5.2.1 多模态传感融合前端

| 传感器类型             | 采集维度             | 技术参数               | 核心作用                   |
| ---------------------- | -------------------- | ---------------------- | -------------------------- |
| IMU（9轴惯性测量单元） | 加速度、角速度、磁场 | MPU-9250, 采样率100Hz  | 捕捉手部运动轨迹与姿态     |
| ToF（飞行时间传感器）  | 距离/深度信息        | VL53L1X, 精度±1mm      | 判断手-脸/手-物体接近距离  |
| 红外热电堆             | 温度梯度             | MLX90614, 精度±0.5°C   | 检测接触行为产生的温度变化 |
| RGB摄像头              | 视频图像             | OV2640, 30fps, 640×480 | YOLO视觉动作识别输入       |
| PPG心率传感器          | 心率/HRV             | MAX30102               | 焦虑水平生理指标关联       |

**融合策略**：

- 时空对齐：基于时间戳同步的多源数据配准（同步误差<5ms）
- 特征级融合：CNN提取空间特征 + Bi-LSTM提取时序特征 → 跨模态注意力融合
- 决策级融合：加权投票机制集成视觉识别结果与传感识别结果

#### 5.2.3 异常检测与行为分类算法

基于 **Bi-LSTM + CNN 双模块联合检测**：

$$
\mathcal{L}_{total} = \alpha \cdot \mathcal{L}_{pred} + \beta \cdot \mathcal{L}_{recon} + \gamma \cdot \mathcal{L}_{class}
$$

其中：

- $\mathcal{L}_{pred}$：预测损失，约束时序建模能力
- $\mathcal{L}_{recon}$：重构损失，约束异常行为特征偏离
- $\mathcal{L}_{class}$：分类损失，约束行为类别区分
- $\alpha, \beta, \gamma$ 为自适应权重系数

**异常评分机制**：
$$AnomalyScore(x) = \lambda \cdot \|x - \hat{x}\|_2^2 + (1-\lambda) \cdot H(p_{pred}, y_{true})$$

异常评分 > 阈值 $\tau$ 时，触发BFRBs识别告警。

| 原则             | 说明                         | 设计表现                                     |

- **正念练习空间**：呼吸引导动画 + 实时生物反馈 + 自然白噪音

### 6.2 核心功能模块详述

#### 模块一：智能行为感知（YOLO视觉 + 多模态传感）

- **温柔感知**：Web端摄像头实时YOLO检测，配以柔焦滤镜与暖色调叠加，让摄像头不再是一个"监视器"，而是一面"温柔的镜子"
- **伙伴陪伴式反馈**：虚拟伙伴"安小宁"在检测画面中陪伴用户——检测到焦虑行为时用温柔气泡提醒（"我注意到你的手靠近嘴巴了哦，没关系，这很正常"），而非警报弹窗
- **多模态融合**：视觉（YOLO）+ 运动（IMU）+ 距离（ToF）+ 温度（红外），多维度交叉验证，准确率≥90%
- **精准分类**：区分8类BFRBs与10类日常动作
- **隐私优先**：所有YOLO推理在浏览器本地完成（ONNX Runtime Web），原始画面永不上传至服务器，仅上传检测摘要JSON
- **感知报告**：每次检测结束生成"温柔版"行为摘要——用色块可视化而非冰冷表格，配以安小宁的鼓励性点评

#### 模块二：情绪健康画像

- **焦虑指数**：基于行为频率、心率变异性(HRV)、自我报告的综合评分
- **行为趋势**：日/周/月行为趋势可视化图表
- **触发分析**：AI识别行为高频触发场景（如考试前、工作会议中）
- **改善追踪**：干预前后的行为变化对比

#### 模块三：数字心理干预

- **💬 安心伙伴AI对话（核心差异化）**：基于大语言模型的流式对话（参考DeepSeek官网风格），专注心理疗愈对话。安小宁以温柔、不评判的语气与用户交流，支持打字机效果逐字输出。内置CBT引导、正念指导、情绪倾诉、行为数据分析等多种对话场景，快捷入口卡片降低表达门槛
- **CBT认知重构**：AI引导的自动化认知行为练习，内嵌于对话流程中
- **HRT习惯逆转**：定制化竞争反应训练，用时<3分钟/次
- **正念减压(MBSR)**：分级正念冥想课程（入门→进阶→深入），配以呼吸引导动画与自然白噪音
- **生物反馈训练**：基于实时心率/呼吸的放松训练
- **情绪日记**：语音/文字输入，NLP自动情绪分析，AI自动生成今日行为摘要与贴纸推荐

#### 模块四：社区与专业支持

- **匿名互助社区**：AI审核 + 人工督导，确保安全交流环境
- **专家问答**：合作心理咨询师定期在线答疑
- **课程中心**：焦虑管理、情绪调节系列精品课程
- **紧急支持**：一键连接24小时心理援助热线
