### 第13页 | 多模态融合 + 异常检测

**标题**：不止于"看见"——多维度智能感知

**技术对比图**：

```
  单一传感器方案              我们的多模态融合方案
  ┌──────────────┐           ┌──────────────────────┐
  │  只测运动 →   │           │  IMU运动  ┐            │
  │  误判梳头=    │           │  ToF测距  ├─ 时空对齐  │
  │  拔头发 ❌   │           │  红外温度  │  特征融合  │
  │              │           │  RGB视觉  ┘            │
  │  准确率~70%  │           │                       │
  └──────────────┘           │  准确率 ≥ 90%  ✅      │
                              └──────────────────────┘

为什么多模态更准确？
──────────────────────────────────────────────
梳头 vs 拔头发：
  单一IMU：都是手臂上扬+手指动作 → 无法区分
  多模态：IMU运动+ToF手距头距离+红外手指温度变化 → 精准区分
```

**异常检测公式（简版）**：

> **行为异常评分 = 预测偏差 + 重构误差 + 分类置信度**

**演讲要点**：

> "为什么必须是多模态？举个简单例子：梳头和拔头发，单一运动传感器根本无法区分，但加上距离传感器和温度传感器之后，就能精准判断——这就是融合的力量。"
