## 三、路由结构

```
/login          → LoginPage         独立布局（无侧边栏）
/               → 重定向 /home
/home           → HomePage          ┐
/detect         → DetectPage        │
/chat           → ChatPage          │
/mindfulness    → MindfulnessPage   ├─ AppLayout
/diary          → DiaryPage         │  （侧边栏 220px + 内容区 1120px）
/profile        → ProfilePage       │
/garden         → GardenPage        │
/me             → MePage            ┘
*               → 重定向 /home
```

React Router v7，`BrowserRouter` + `Routes` + `Route`，嵌套布局路由。
